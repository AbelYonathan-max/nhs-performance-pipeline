# NHS performance pipeline

A monthly data pipeline for two NHS England performance collections, feeding a
Power BI report and an Excel reporting pack.

- **A&E**: attendances, the 4-hour standard and 12-hour trolley waits, by trust.
- **Referral to treatment (RTT)**: the elective waiting list, 18-week performance,
  52-week waits and median waits, by trust and specialty.

Data runs from April 2023 to the latest published month.

## What it does

```
NHS England website ──fetch──> data/raw (CSV + zip, with a SHA-256 manifest)
        │
      build     clean with pandas, run data quality checks, load a SQLite star schema
        │
     forecast   scikit-learn backtest and 6-month forecasts, flag unusual months
        │
  export/excel  Parquet files for Power BI + the Excel reporting pack (data/out)
        │
     analyse    R rebuild and trend check, scenarios, gap to target, one-page brief (data/analysis)
        │
     publish    commit data/out to this repo's `data` branch
        │
   Power BI     reads the Parquet files from the data branch
```

| Stage | Code | Notes |
|---|---|---|
| Fetch | `src/nhs_pipeline/fetch.py` | Finds each month's file from its link text on NHS England's yearly pages; one request a second; skips files already held. |
| Clean | `src/nhs_pipeline/transform.py` | Matches columns by normalised name, so small header changes between years don't break it. RTT rows are summed over commissioners; medians are interpolated from the weekly bands. |
| Warehouse | `src/nhs_pipeline/sql/schema.sql`, `views.sql`, `warehouse.py` | Star schema (month, region, organisation, specialty dimensions; A&E and RTT facts) with constraints, reporting views and league tables in SQL. |
| Quality checks | `warehouse.quality_checks` | Duplicate keys, missing months, negative counts, 4-hour breaches above attendances, specialties adding up to the total, sudden swings. A failed "error" check stops the load. Results are stored and shown in the report. |
| Forecast | `src/nhs_pipeline/forecast.py` | One gradient boosting model per measure across all trusts, predicting next month's change from recent changes and seasonality. A rolling backtest scores it against "same as last month" and "same as a year ago"; the best method is used, with 80% ranges from its own backtest errors. Robust z-scores flag unusual months. |
| Excel pack | `src/nhs_pipeline/excel_pack.py` | Contents, England summary against targets, trust lookup (dropdown), A&E and RTT league tables, regions heatmap, forecasts, data quality, definitions. Figures are live `SUMIFS` / `INDEX-MATCH` formulas over the data sheets. |
| R check and trends | `r/england_trends.R` | Rebuilds the England series from the trust-level Parquet files in R and stops if they differ from Python's. Fits a linear trend with month-of-year seasonality (95% confidence intervals), projects each rate to its target date with a 95% prediction interval, and draws a chart per rate with ggplot2. |
| Scenarios | `src/nhs_pipeline/scenarios.py` | Projects England to the next target date under unfavourable, central and favourable assumptions (worse quartile, median and better quartile of past monthly changes, seasonality kept). Gap to target: the monthly change needed against how often it has happened. |
| Brief | `src/nhs_pipeline/brief.py` | A one-page plain-English summary for non-specialists, with every number read from the outputs. |
| Power BI | `powerbi/` | Power BI project (PBIP): TMDL semantic model with 47 DAX measures and a 6-page PBIR report, generated by `powerbi/generate.py`. |

## Run it

Python 3.12 or later.

```
python -m venv .venv
.venv\Scripts\activate            # Windows (source .venv/bin/activate elsewhere)
pip install -e ".[dev]"
nhsp all                          # fetch, build, forecast, export, excel
nhsp analyse                      # R check, scenarios, gap to target, brief
nhsp publish                      # push data/out to the data branch
```

`nhsp analyse` needs R 4.3+ with the `ggplot2` and `nanoparquet` packages for
the R step (`install.packages(c("ggplot2", "nanoparquet"))`); without R it
skips that step and still writes the scenarios and brief.

Each step also runs on its own: `nhsp fetch`, `nhsp build`, `nhsp forecast`,
`nhsp export`, `nhsp excel`. Outputs go to `data/` (git-ignored).

NHS England's website turns away requests from cloud servers, so the download
runs on an ordinary PC. `scripts/refresh.ps1` does the whole monthly run on
Windows, and `scripts/register-task.ps1` schedules it for the second Friday of
each month (NHS England publishes on the second Thursday).

## Power BI

Open `powerbi/NHS Performance.pbip` in Power BI Desktop and refresh. The model
reads the Parquet files from this repo's `data` branch through the `DataRoot`
parameter, so it also refreshes on a schedule in the Power BI service without a
gateway.

Pages: Overview, A&E, Waiting lists, Trust view, Forecast, Data quality.

After changing a table, measure or visual, edit `powerbi/generate.py` and run
`python powerbi/generate.py`. CI checks the generated files are up to date,
validates the report against Microsoft's PBIR JSON schemas, and loads the model
with Microsoft's Tabular Object Model (`powerbi/TmdlCheck`).

## Results

First full run, 4 November 2026: A&E April 2023 to September 2026, RTT April 2023
to August 2026.

- Loaded 655 organisations, 8,329 A&E rows and 760,041 RTT rows (provider ×
  specialty × pathway type) from 83 files. All 14 data quality checks passed.
- Figures match NHS England's published headlines, for example A&E 4-hour
  performance of 74.6% in April 2023.
- England, latest month:

  | Measure | Latest | Same month last year | Target this year |
  |---|---|---|---|
  | A&E seen within 4 hours (Sep 2026) | 74.4% | 75.1% | 82% (not met) |
  | 12-hour trolley waits (Sep 2026) | 50,582 | 44,765 | |
  | RTT waiting list (Aug 2026) | 7.19 million | 7.35 million | |
  | RTT waiting under 18 weeks (Aug 2026) | 65.2% | 60.9% | 70% (not met) |
  | RTT waiting over 52 weeks (Aug 2026) | 112,958 (1.6%) | 192,024 (2.6%) | under 1% (not met) |

- Forecast backtest (6 origins, 1 to 6 months ahead, mean absolute error):

  | Measure | Gradient boosting | Same as last month | Same as a year ago | Used |
  |---|---|---|---|---|
  | A&E 4-hour % (points) | 2.66 | 3.18 | 3.78 | Gradient boosting |
  | A&E attendances | 4.3% | 6.4% | 5.1% | Gradient boosting |
  | RTT 18-week % (points) | 2.52 | 2.85 | 4.90 | Gradient boosting |
  | RTT waiting list | 5.0% | 4.7% | 9.3% | Same as last month |

- Data quirks handled: 14 trusts testing new A&E standards in April and May 2023
  reported no 4-hour figures, so they are left out of 4-hour percentages for those
  months; new RTT referrals come only as a total, with no weekly bands; providers
  that appear only in the RTT file take their region from their integrated care
  board.
- The Excel pack has 2,916 live formulas and recalculates with no errors.

### Analysis, 5 November 2026

- **Independent check:** the R rebuild of all four England series matched the Python
  figures exactly.
- **Trend since April 2023** (linear, seasonality fitted, 95% confidence interval):

  | Measure | Change a year | Change a year needed to hit next target |
  |---|---|---|
  | A&E seen within 4 hours | +1.0 points (0.7 to 1.3) | +15.4 points (82% by March 2027) |
  | RTT waiting under 18 weeks | +2.3 points (1.9 to 2.7) | +8.3 points (70% by March 2027) |

- **Gap to target:** reaching 82% for A&E needs a rise of 1.3 points every month for
  6 months; only 12% of past months improved that much. Reaching 70% for 18-week
  waits needs 0.7 points a month for 7 months; 18% of past months managed it.
- **Scenarios for March 2027** (unfavourable / central / favourable): A&E 4-hour
  74.1% / 75.9% / 78.6%; RTT 18-week 64.9% / 66.5% / 68.6%. Neither target is met in
  any scenario.
- Assumptions, checks and limitations: [docs/assumptions-and-qa-log.md](docs/assumptions-and-qa-log.md).
  Example output from this run, including the brief and charts: [docs/example-output](docs/example-output/brief.md).

## Tests

```
ruff check src tests powerbi

```

and run every stage on them, including a LibreOffice recalculation of the Excel
pack when LibreOffice is installed and the R rebuild check when R is installed
(CI installs both R and its packages).

## Data protection

All inputs are aggregate statistics about organisations, published by NHS
England under the Open Government Licence v3.0. No patient-level or personal
data is collected, stored or derived, so no personal data is processed under
UK GDPR. Figures are reproduced as published; NHS England applies its own
disclosure control before release. Each source file's URL and SHA-256 hash is
kept in the manifest and shown in the report, so every figure can be traced to
its file.
